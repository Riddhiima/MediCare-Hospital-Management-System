# Project Statement

## Project Title

MediCare Hospital Management System

## Problem Statement

Small and medium-sized hospitals need a simple way to organize patient, doctor, appointment and billing information. Maintaining these records manually can make searching, updating and managing information difficult.

The MediCare Hospital Management System provides a command-line Python application that organizes these basic hospital operations in a structured and easy-to-use system.

The project focuses on demonstrating Python programming concepts such as Object-Oriented Programming, database connectivity, input validation, error handling and unit testing.

## Scope

The project covers the following core hospital management functions:

- Patient registration and management
- Doctor management
- Appointment booking and cancellation
- Billing management
- SQLite database storage
- Input validation and error handling
- Basic unit testing

The project is intended for academic use and uses sample data only.

The current version intentionally does not include advanced hospital functions such as medical records, admission and bed management, laboratory management or online payment processing.

## Target Users

- Reception staff
- Hospital administrators
- Doctors
- Billing staff

## High-Level Features

1. Patient Management
2. Doctor Management
3. Appointment Management
4. Billing Management
5. SQLite Database Management
6. Data Validation and Error Handling
7. Unit Testing

## Technical Requirements

- Python 3
- SQLite
- Object-Oriented Programming
- Command-Line Interface (CLI)
- Python `unittest` framework

## Non-Functional Requirements

- **Usability:** The system should provide simple menu-based navigation.
- **Reliability:** Invalid inputs should be handled without unexpectedly terminating the application.
- **Data Persistence:** Patient, doctor, appointment and billing data should be stored in the SQLite database.
- **Maintainability:** The system should be divided into separate modules for easier maintenance and understanding.
- **Validation:** Important user inputs should be validated before being stored or processed.
